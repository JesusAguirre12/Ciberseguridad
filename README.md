#  CTF & Web Security Write-ups

Soluciones explicadas paso a paso para desafíos de **picoCTF**, **PortSwigger Web Security Academy**, la plataforma **italiana (OliCyber)** y las olimpiadas de la **ICO (International Cybersecurity Olympiad)** entre otras, pero estas son las más destacadas.

A diferencia de los write-ups típicos que te dan el payload final directo, estas explicaciones documentan mi **proceso de resolución en tiempo real**: la metodología, las hipótesis que probé (incluso las que fallaron), los errores, la automatización con scripts y cómo fui conectando los puntos hasta conseguir la flag.

---
